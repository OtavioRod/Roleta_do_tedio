# Roleta do tedio

Problema Identificado: A "fadiga de decisão" enfrentada por casais e grupos de amigos que perdem tempo e se estressam tentando decidir o que fazer no lazer (como o que comer ou assistir no sábado à noite).

​Objetivo: Eliminar o atrito e a indecisão através de uma dinâmica gamificada, cruzando os humores dos participantes e sorteando uma atividade obrigatória por meio de uma roleta interativa.

Público-alvo: Casais, grupos de amigos e jovens que buscam otimizar momentos de lazer sem o peso de ter que escolher tudo sozinhos.
​Principais Funcionalidades:
​  Tela de escolha de humor/mood individual (ex: "com preguiça", "com fome", "quero gastar pouco").
​  Sincronização em tempo real das escolhas dos participantes.
​  Roleta interativa e animada que cruza os dados e define a atividade final para o grupo

Tecnologias Previstas:
​React Native (Expo) para o desenvolvimento multiplataforma (iOS e Android).
​Firebase Firestore para a sincronização de dados em tempo real.
​Bibliotecas de animação para a roleta interativa.
